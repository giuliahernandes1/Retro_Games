# 🎮 GameZone Retrô

> A melhor loja de jogos clássicos da cidade!

Este é um projeto simples em HTML desenvolvido para apresentar a **GameZone Retrô**, listando consoles disponíveis, tabela de preços dos jogos clássicos e atalhos para redes sociais.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação de conteúdo, listas, tabelas e links.

## 📌 Funcionalidades

- **Apresentação:** Informações principais da loja.
- **Catálogo de Consoles:** Lista dos sistemas retrô disponíveis (SNES, NES, Game Boy, Sega Genesis).
- **Tabela de Preços:** Lista detalhada com jogos, suas respectivas plataformas e valores.
- **Redes Sociais:** Link direto para a consulta de preços no Instagram.

## 📁 Estrutura do Arquivo

```text
├── Loja_GamesRetro.html   # Arquivo principal do projeto

```

## 🛠️ Como Executar o Projeto

1. Clone este repositório para a sua máquina:
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```

2. Navegue até a pasta do projeto e abra o arquivo `Loja_GamesRetro.html` em qualquer navegador web.

> 💡 **Dica:** Para exibir a imagem da página corretamente no GitHub ou na máquina de outras pessoas, recomendamos mover a imagem para uma pasta local do projeto (ex: `assets/` ou `images/`) e atualizar o caminho no atributo `src` da tag `<img>`.
